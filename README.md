# AI Resume Analyzer 📄🤖

An AI-powered application to analyze resumes and match them with job descriptions using Natural Language Processing (NLP).

This project helps recruiters and job seekers by automatically extracting skills, scoring resumes, and providing insights.

### 🚀 Live Demo
> Add your Streamlit / deployed link here if you have

### ✨ Features
- **Resume Parsing:** Extracts name, email, skills, education from PDF resume
- **Skill Matching:** Compares resume skills with job requirements
- **ATS Score:** Gives a match score (0-100%) for the resume
- **AI Feedback:** Suggests improvements to make resume stronger
- **Interactive App:** Built with Streamlit for easy use

### 🛠️ Tech Stack
- **Python**
- **Streamlit** - for Web App (app.py / resume_app.py)
- **PyPDF2 / pdfplumber** - for reading PDF
- **Scikit-learn, NLP** - for analysis
- **Pandas, NumPy**

### 📁 Files in this Repo
- `AI_Resume_Analyzer.ipynb` - Main analysis notebook
- `resume_app.py` / `app.py` - Streamlit web application
- `Resume.pdf` - Sample resume for testing
- `requirements.txt` - All required libraries
- `churn_model.pkl` & `customer churn.ipynb` - Extra practice projects
